# Distance and Temperature Sensing Using Arduino Uno

## 📋 Project Overview
This project demonstrates how to use Arduino Uno to measure distance and temperature using external sensors.

## 🎯 Features
- **Temperature Sensing** - Real-time temperature monitoring
- **Distance Measurement** - Accurate distance detection
- **Data Display** - Serial monitor output for easy reading

## 🛠️ Hardware Requirements
- Arduino Uno
- Temperature Sensor (e.g., DHT11/DHT22 or LM35)
- Ultrasonic Sensor (HC-SR04) for distance
- Breadboard
- Jumper Wires
- USB Cable for programming
